# Tutorial Git Conflict

Ini adalah repository tutorial untuk belajar **Git** dan **Vercel**.

## Deskripsi Proyek
Proyek ini dibuat untuk mendemonstrasikan deployment otomatis menggunakan Vercel,
sekaligus berkolaborasi dalam tim menggunakan Git secara profesional.

## Cara Menjalankan
1. Clone repository ini
2. Buka file `index.php` di browser lokal
3. Deploy ke Vercel dengan `vercel --prod`

## Anggota Tim
- Anggota 1 (dari branch master)
- Anggota 2 (dari branch feature-conflict-demo)
- Anggota 3 (baru bergabung di master)

## Catatan
Conflict berhasil diselesaikan! ✅🚀
Gabungan dari master dan feature-conflict-demo.
